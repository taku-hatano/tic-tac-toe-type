以下の手順に従ってPRを作成してください。

## 1. マージ先の判定
- $1で指定したブランチをマージ先としてください
- マージ先が指定視されなかった場合はそこで処理を終了し、ユーザーにブランチを指定するように指示してください。

## 2. 変更内容の取得
以下のコマンドを実行して変更内容を取得してください。

```console
bash .claude/tools/get_change.sh "$1"
```

## 3. PR説明文の作成
これまで取得した変更内容等の情報を元に、@.github/pull_request_template.md をテンプレートとしてPRの説明部分を考えてください。
作成時には以下の項目を埋めてください。

- 概要
  - 本ブランチでの対応の背景を簡潔にわかりやすく記載する
    - 対応のもととなった事象の概要
    - 対応方針
- どのような変更か
  - 取得した差分情報を元に具体的にどのような変更かを記載する
  - すべてのファイルを網羅する必要はなく、主たる変更内容がレビュワーに伝わりやすい内容を心がけること

## 4. PRの作成
以下のコマンドを実行して、PRを作成してください。

```console
bash .claude/tools/create_pr.sh "タイトル" "説明" "ベースブランチ"
```
